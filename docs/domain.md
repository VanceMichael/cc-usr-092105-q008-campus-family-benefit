# 领域约定

## 核心对象

- 新生资格：院校对通知书持有人给出的资格结论，只含结论，不含学籍明细
- 家庭成员：家庭自行声明的随行亲友及其关系，商户不另行核验学籍
- 城市权益：商户发布的优惠，必须带额度、生效期和适用对象
- 规则版本：权益规则的快照，核销时冻结，事后争议以冻结版本为准
- 商户核销：一次权益使用记录，区分新生权益与亲友优惠
- 撤销记录：核销被撤销时必须留下的原因
- 异常复核：对重复、超额或越权核销的事后核查
- 回访同意：家庭对核销记录被用于回访的授权
- 家庭账单：面向家庭的一致视图，汇总各业态的核销、撤销与返还
- 结算记录：商户月底按真实核销记录结算的依据

## 资格与声明

- 院校只返回资格结论
- 随行关系由家庭自行声明

## 权益与核销

- 每项权益按自己的次数约束核销
- 同一张通知书可在不同业态分别使用，各业态额度互不占用
- 亲友优惠不得冒充新生权益
- 核销时冻结所适用的规则版本
- 撤销核销必须记录原因
- 断网期间的核销先离线登记，恢复后补传，按通知书和权益去重
- 跨商户并发核销以单项额度为上限，冲突或超额部分进入异常复核
- 退订后返还对应权益额度

## 回访与结算

- 未经同意不得把核销记录用于回访
- 家庭账单与各商户台账保持一致
- 结算以真实核销记录为准

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
