# 领域约定

## 核心对象

- 新生资格：院校只返回资格结论与有效期，学籍详情不出校
- 家庭成员：同行关系由家庭自行声明，平台不核验亲属关系
- 城市权益：商户发布时必须带额度、生效期和适用对象（新生 / 随行亲友）
- 权益规则版本：权益规则按版本管理，核销时冻结当时版本
- 核销记录：一次核销对应一个权益、一名成员和一份冻结的规则版本
- 撤销记录：撤销必须留下原因，并引用被撤销的核销
- 退订记录：退订后占用的额度即时返还
- 离线补传批次：断网期间的核销先本地暂存，恢复后按批次补传并去重
- 异常复核：并发冲突、超次等异常先复核，复核结论才可调整账单与结算
- 回访同意：核销记录用于回访前必须取得家庭同意
- 家庭账单：按核销、撤销、退订记录向家庭呈现一致账单
- 结算记录：商户月底按真实核销记录结算

## 已知规则

- 院校只返回资格结论
- 每项权益按自己的次数约束核销；同一通知书可跨业态使用，但不得突破单项次数
- 亲友优惠不得冒充新生权益，核销按适用对象校验
- 核销时冻结规则版本，撤销必须记录原因
- 离线核销须补传并按通知书与权益去重
- 跨商户并发核销以家庭与权益为粒度互斥
- 退订后额度返还
- 未经同意不得把核销记录用于回访
- 家庭账单与商户结算都以真实核销记录为准

## 对象关系

- 一份新生资格对应一份家庭声明，声明下列出新生与随行亲友
- 一张通知书（资格凭证）可在住宿、文化场馆、交通接驳等多个业态分别核销，各业态按自己的权益规则计数
- 每条核销记录冻结一份权益规则版本；撤销、退订、复核都挂在核销记录上
- 家庭账单与商户结算记录都由同一组真实核销记录汇总而来，保证两边一致

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
