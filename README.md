# 送学家庭城市礼遇核销

保存高校新生家庭使用城市礼遇时的资格与核销约定。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料覆盖了以下约定：

- 院校只确认新生资格结论，不外泄学籍详情；随行关系由家庭自行声明
- 商户发布的权益带额度、生效期和适用对象，样例覆盖住宿、文化场馆与交通接驳
- 同一张通知书可跨业态分别核销，受单项次数约束，亲友优惠不得冒充新生权益
- 核销时冻结规则版本，撤销必须记录原因，断网期间的核销可离线登记并补传去重
- 退订返还额度，异常核销进入复核，回访需经家庭同意
- 家庭看到一致账单，商户月底按真实核销记录结算

## 校验方式

在仓库根目录运行 `npm test`。测试会读取样例并核对领域标识、对象清单、规则清单与样例要素是否完整。
