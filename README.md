# 送学家庭城市礼遇核销

保存高校新生家庭使用城市礼遇时的资格与核销约定。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 开学季家庭会在高校周边住宿并延伸城市游
- 多地向新生和随行亲友提供跨业态优惠
- 录取通知书被用作现场资格凭证
- 同一张通知书可在住宿、文化场馆、交通接驳等业态按各自规则核销
- 线下场景可能断网，核销记录需要事后补传
- 商户月底按真实使用记录与平台结算

## 校验方式

在仓库根目录运行 `npm test`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整。
